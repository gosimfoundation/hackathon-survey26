## 1. 练习赛 / Playground

当前比赛为 Playground。报名、组队、提交和查分都在本站完成，无需选择比赛阶段。

1. 每人一个账号，每人只能属于一支队伍，队伍最多 3 人，个人参赛也需创建队伍。
2. 在「找队友」的队伍列表点击队伍，可发送加入申请；队长接受后加入。也可向选手发送邀请，由对方接受或拒绝。
3. 右上角「组队通知」显示收到与发出的申请、邀请及处理进度。邀请码与邀请链接仍可使用。
4. 主办方、评测平台维护者及直接合作者可练习，但不参与评奖，其队伍在公开榜单隐藏。

## 2. 提交

1. 在本地运行自己的算法，生成 `decisions.csv`，通过「提交」上传。语言与算法不限，不强制使用大模型。
2. CSV 列为 `decision_id, slot_id, action, tile_id, program, request_id, reason`，最大 20 MB。
3. 每队每天最多提交 50 次，以页面显示的实际额度为准。选择与本地运行相同的场景；平台自动选择当前比赛。
4. 入门包包含公开场景、示例策略、运行器、评分器和回放工具。模型密钥只用于自己授权的调用，不得写入提交文件。
5. 也可以在「参赛」页提交完整项目（公开 GitHub 仓库或 ZIP），即「练习赛 · 完整项目」赛道。平台在云端逐轮运行你的程序（和比赛相同的评测流程），使用公开场景 dev-fortnight 和 dev-reference，每个场景运行时限 5 小时（18000 秒）。每队每天 5 次，按 UTC 0 点（北京时间 8 点）重置，因平台原因失败的不计次数。调用模型只能使用本队自己的模型 API 密钥。成绩进单独的完整项目榜，不决定奖项。建议在 10 月 2–3 日培训前后用它把云端评测流程走一遍。
6. Kimi Coding Plan：跑通练习赛（至少获得一次成功评分：CSV 提交已评分，或完整项目评测已评分）的队伍，每队获得一个 Kimi Coding Plan 兑换码（即将发放）。组委会发放后由队长在控制台领取，全队成员都能在控制台查看。使用时接口填 `https://api.kimi.com/coding/v1`，模型填 `kimi-for-coding` 或 `k3`。隐藏队伍和测试队伍不参与发放。

## 3. 评分与排名

平台用公开的 `scoring_core.py` 和对应场景的 `score_config.json` 评分，规则与已有成绩保持一致。

- `observe` 观测天区，`wait` 等待；时隙长度为 900 秒，曝光可跨时隙。
- 科学分取决于天区价值、完成的曝光时长、天气和几何条件；匹配的观测项目可获得加成。
- 完成观测请求可以获得奖励；不安全观测、无效动作、可避免等待、必做天区未完成、分区覆盖不足和请求未完成会扣分。
- 只有完成曝光才计科学分。天气中断不罚；几何或夜晚结束导致的中断按无效动作处理。
- 重复观测合法，每个天区保留最高观测分。练习场景不启用隐藏异常上报机制，覆盖均匀性额外奖励权重为 0。
- 每个场景分别排名，每队保留该场景的最高分；严格同分时先提交者在前。练习榜用于练习，不决定奖项。

提交详情提供得分组成、完成情况、回放和结果下载。使用同一场景和官方评分器可复核 `decisions.csv` 的成绩。

## 4. 行为与隐私

保持尊重，不共享账号，不提交他人成果，不建立多个队伍放大额度。不得读取其他队伍私有数据、篡改评分或故意耗尽平台资源。发现问题请报告主办方。

队名、分数和名次公开。姓名、邮箱、单位和 GitHub 信息用于赛事运营；公开名片由选手自行设置。提交文件及详细运行结果仅向本队和主办方开放，保留至颁奖日后 90 天。已有提交、成绩与回放均保留。

奖项安排与活动通知见公告。联系方式：hackathon@gosim.org
