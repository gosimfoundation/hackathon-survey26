## 1. 注册并加入队伍

注册账号后，进入「找队友」。可以创建队伍，也可以点击一个队伍发出加入申请，由队长接受或拒绝。右上角通知中可以接受别人发来的邀请。每队最多三人，单人参赛也需要创建队伍。

## 2. 准备完整项目

项目语言不限，读取当前观测数据后逐轮返回决策，不强制调用模型。接口说明和示例项目见[文档](/docs)。

## 3. 提交完整项目

显著位置的「提交」按钮统一进入[参赛](/compete)。填写公开仓库链接或上传私有 ZIP，审阅源码版本、启动设置和提出的接口文件，再确认用于评测的版本。不接受 CSV。

模型调用可选，需要时请自备 API 和额度。不要把密钥放进项目。

使用模型时，在「参赛」页填写支持 HTTPS 的接口、模型和密钥，并选择处理方式：

- **不保存（默认）**：密钥只留在页面里；每次评测都要保持页面打开直到结束，比赛结束后的隐藏决赛评测期间也要打开。进入前列需要复现核验时，也要按约定时间打开页面配合。
- **加密保存（需主动选择）**：密钥加密保存在服务器上，比赛结束、成绩核实后自动删除；评测时无需保持页面打开。

## 4. 评测并查看结果

每批评测覆盖三个固定的正式场景（A、B、C），所有队伍相同；场景文件和未来天气不公开，观测逐步提供。每日次数内可自由评测。平台先记录本轮决策，再发放下一轮观测。

结果包含得分、得分组成和运行记录。全部场景完成后才进入线上榜，榜单显示本队最高分的完整批次，只作实时反馈。

下载结果可以查看每次决策和运行失败原因。运行时限与 API 额度以参赛页显示为准。评测无法完成时，可通过[公告](/announcements)联系主办方。

## 5. 选定最终版本

在「参赛」页的**最终版本**栏，把一个已确认的版本设为本队最终版本。比赛结束（10 月 7 日 23:59，UTC+8）前可随时更改或取消；未选择时默认使用本队最高分评测的版本。比赛结束后，主办方在一个隐藏场景上对每队的最终版本评测一次，**最终排名只看这个隐藏场景的成绩**，结果在主办方公布前保密。
