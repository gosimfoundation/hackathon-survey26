不需要懂命令行，也不用装任何第三方库。跟着走一遍，大约 20 分钟就能把第一个成绩挂上排行榜。

整件事就三件：**跑起来 → 改一个函数 → 上传**。

## 第 1 步 · 注册账号

点页面右上角的「报名」，填姓名、邮箱、密码，勾上"我已阅读规则"，点「创建账号 →」。

**不用去邮箱点确认链接**，提交完就直接登录进「控制台」了。GitHub 用户名和所属机构可以留空，以后在「个人资料」里补。

## 第 2 步 · 建一个队伍

控制台会提示"你还没有队伍"。点「队伍 →」，填个队名，点「创建队伍 →」。

**一个人参赛也要建队伍**——成绩是按队伍记的。建完会给你一个邀请码（形如 `E3SE6NE9`），队友在「队伍」页填这个码就能加入，最多 3 人。

## 第 3 步 · 下载入门包，先跑通

控制台右侧有「下载入门包 ↓」（「资源」页也有）。下下来解压，得到一个 `agent-observer-starter-kit` 文件夹。

进文件夹，按你的电脑双击对应的文件：

| 你的电脑 | 双击这个 |
|---|---|
| macOS | `run_baseline.command`（系统自带的 Python 就够用；如果提示"无法打开"，右键 →「打开」） |
| Windows | `run_baseline.bat`（先去 [python.org](https://www.python.org/downloads/) 装 Python 3.12，**安装时记得勾上 Add python.exe to PATH**） |
| Linux | 终端里运行 `./run_baseline.sh` |

约 15 秒后会自动弹出一个网页，那是基线智能体在 180 个观测夜上的回放。终端最后一段是分数：**基线大约 12287 分**，`termination_reason` 显示 `survey_complete` 就说明一切正常。

> **想先快速看一眼？** 把文件名里的 `run_baseline` 换成 `run_demo_week`，是 7 个观测夜的演示场景，2 秒跑完，回放也更容易一夜一夜看清楚。

## 第 4 步 · 只改一个函数

打开 `agent/my_strategy.py`。**整个比赛你只需要改这个文件里的 `choose_action` 函数。**

它的工作很简单：

- 平台把"这一时隙能观测的候选"排好序交给你，第 0 个是系统估计收益最高的；
- 你挑一个返回，或者返回 `None` 表示这一时隙先等着。

文件里已经写好了几条思路，取消注释就能用：优先补必做天区（REQUIRED）、优先响应观测请求、条件差的时候等待、用 `memory` 记住已经做过什么。每个候选带哪些字段、各是什么意思，都写在文件开头。

改完保存，再双击一次 `run_baseline`，看分数有没有涨。跑出错的话，终端会直接把 `agent.log` 的最后几行打出来。

## 第 5 步 · 上传

回到网站，点「提交」，选场景（比赛由平台自动选择），把刚才本地跑出来的 `run_output/decisions.csv` 拖进框里，点「上传并排队评测 →」。几秒钟出分。

以上流程用于练习赛。正式赛只接受完整项目：在「参赛」页提交公开仓库或私有 ZIP，平台在三个固定正式场景上逐步评测，未来天气不公开。比赛结束后，每队选定的最终版本还会在一个隐藏场景上评测一次，最终排名只看这个成绩。

想提前熟悉评测流程，在「参赛」页选「提交完整项目」：入门包里运行 `python3 pack_agent.py` 就能打出可上传的 ZIP。平台在云端逐轮运行你的程序（和比赛相同的评测流程），使用公开场景 dev-fortnight 和 dev-reference，每队每天 5 次，调用模型只用本队自己的密钥，成绩进单独榜单。建议在 10 月 2–3 日培训前后这样走一遍。

## 第 6 步 · 看结果

上传后页面会显示排队位置和评测进度，通常一两分钟出分。点进这条提交，能看到：

- **分数分解** —— 基础科学分、项目加成、请求奖励，以及各项扣分分别是多少
- **逐夜回放** —— 每个观测夜实际做了什么，哪些天区亮了、哪些没排上

排行榜在顶部导航「排行榜」里，实时更新。

## 进阶 · 想拿正式赛的分？先学会抓异常

正式比赛场景里埋了三种异常：带隐藏标签的天区（nova 真实得分 ×1.5、reddening ×0.8）、一次不广播的仪器故障（某片区域效率骤降），以及每晚的效率小抖动。发现并上报它们有加分，乱报有扣分——这是正式赛拉开差距的地方，Playground完全没有这些。

演练方法：在入门包里双击 **`run_finals_preview`**（用法和上面完全一样）。约一秒跑完，基线 **约 8214 分**；打开回放和 `decisions.csv`，能看到示例智能体自己完成的 `report_instrument_failure` 上报行。想让你的策略也能抓异常，看 `agent/anomaly_detection.py` 里的现成示例——快照里的 `tile_last_finished`（上次曝光的真实得分）就是全部线索的起点。

规则细节在「赛事说明 · 正式赛新机制」一节和「规则」页。

## 卡住了？

| 情况 | 怎么办 |
|---|---|
| 双击没反应 / 提示找不到 Python | Windows 要先装 Python 3.12 并勾选 Add to PATH；macOS 右键 →「打开」 |
| 上传后一直排队 | 正常，评测机在逐个跑；场景大的时候要等一会儿 |
| 提交立刻变成 `invalid` | 多半是文件不对。要传的是本地运行后生成的 `run_output/decisions.csv`，场景要和本地跑的一致 |
| 想在本地多试几种天气 | `python3 make_scenario.py --out scenarios/mine --seed 7 --days 30`，再 `python3 local_runner.py --scenario scenarios/mine --agent agent/minimal_agent.py` |
| 想让大模型参与决策 | 复制 `agent/.env.example` 为 `agent/.env`，填好自己的 key（平台不提供模型额度），在本地运行，照常上传生成的 `decisions.csv` |

更细的数据格式、协议和评分公式在「文档」页；入门包里的 `README.md` 是给工程师看的完整版。

有其他问题看「常见问题」页，或者在「公告」页找主办方联系方式。
